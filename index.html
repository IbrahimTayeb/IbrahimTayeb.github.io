Flowboard

Real-time Kanban board where every card drag, comment, and label update syncs live across tabs. Built the whole data layer around Supabase Postgres with row-level security, so each guest gets a fully isolated, persistent board with zero custom backend code.

Column reordering uses a floating-point position column so dropping a card between two others only ever writes one row, not a re-indexed column. Optimistic UI updates on drag, reconciled against Postgres change events over a Realtime subscription.

Systematic Trading Engine

A market microstructure research platform: ingest live or simulated order-book data, engineer features, generate ML-driven alpha signals, then backtest and paper-execute the resulting strategy through a simulated execution layer — all from one Streamlit dashboard.

Split into independent modules (ingestion, feature engineering, signal generation, backtesting, execution simulation) so any one piece — say, the alpha model — can be swapped without touching the rest of the pipeline.

NetworkChessStrike

A desktop chess app supporting local play, real-time networked multiplayer over raw TCP sockets, and a custom AI opponent — with drag-and-drop pieces, live in-game chat, and configurable time controls.

The AI uses alpha-beta pruning with iterative deepening for time-bounded move search, evaluating material, mobility, and king safety. Networking, AI search, and the countdown timers each run on their own thread so the GUI never blocks. Games save/load as JSON with PGN export.
